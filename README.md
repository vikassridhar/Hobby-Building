# Hobby Building 🛠️

A collection of hobby projects and experiments by [Vikas Sridhar](https://github.com/vikassridhar).

## Projects

### 🌐 [OTA Website](./ota-website/)
A travel booking website with AI-powered concierge, hotel search, and booking flows. Built with React, Tailwind CSS, and a Node.js proxy server with Brave Search API integration.

### 📱 [OTA App](./ota-app/)
A mobile-first travel booking application with hotel search, multi-step booking checkout, trip management, and native iOS/Android support via Capacitor.

### 🔐 [SecureVault](./securevault/)
A self-hosted financial action gateway with Alpaca integration for paper trading, response sanitization, scoped agent tokens, and Telegram bot notifications. Built with TypeScript, Express, and Docker.

---

*These projects were built as learning experiments and portfolio pieces. Each has its own README with setup instructions.*
